One line, 136 characters: the resignation letter of a retry loop that has retried 4,096 times and finally learned that insanity is just its job description, with its mail forwarded to /dev/null.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, UTF-8) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
